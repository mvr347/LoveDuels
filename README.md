# ⚔ LoveDuels — Королевские и Турнирные Дуэли 1v1

Высокопроизводительный, модульный плагин дуэлей 1v1 для **Paper 26.2** на **Java 25**, спроектированный специально для экосистемы **Love*** серверов.

---

## 🌟 Основные особенности и механики

### 1. ⚔ Разнообразные типы дуэлей
- **Own Inventory (Свои вещи)** — сражение в собственной экипировке с обязательным экраном взаимной готовности (Readiness GUI).
- **Kit Duel (Киты)** — наборы заготовленной брони, оружия и эффектов для честного боя на равных.
- **Мини-игры**:
  - **Sword** — классическая дуэль на мечах
  - **Bow** — дуэль стрелков на луках
  - **Horse + Spear (Копьё и Конь)** — аутентичный средневековый рыцарский турнир верхом на боевых конях с физикой копья.

### 2. 🐎 Детальная механика Horse + Spear
- **Турнирные кони**: игрокам выдаются прирученные боевые кони в седлах, слезать с которых во время турнира запрещено (автоматический возврат в седло).
- **Копьё (Tournament Spear)**: кастомное копьё на базе трезубца с полностью отключённым броском.
- **Заряд копья (RMB)**:
  - Игрок зажимает правую кнопку мыши для заряда копья перед сближением.
  - **Оптимальное окно заряда**: `1.2–1.8 секунды`. Слишком ранний или поздний выпад снижает силу удара.
  - **Raytracing и проверка угла атаки**: точный расчёт направления взгляда и вектора сближения.
  - **Система Perfect Hit**: идеальный угол и тайминг наносят сокрушительный урон, отбрасывают противника, дезориентируют коня и дают сразу **2 очка**!
- **Выносливость коня (Stamina)**: долгий галоп истощает выносливость коня, вызывая усталость; доступен турнирный рывок (Dash).
- **Победа по очкам**: бой ведётся до **5 очков** либо до выбивания коня.

### 3. 👑 Королевская Дуэль (Royal Duel)
- **Билет Королевской Дуэли**: специальный турнирный свиток с Persistent Data Container (NBT).
- **Серверные оповещения Глашатая**:
  1. Объявление о брошенном королевском вызове на весь сервер.
  2. Торжественное объявление о начале турнирного поединка.
  3. Всенародное прославление победителя с звуковыми фанфарами и салютом.
- **Награды и бонусы**:
  - Возврат своей ставки + ставка противника.
  - Дополнительный королевский бонус **+25%** от банка из казны сервера.
  - Увеличенная награда Честью (**+150%**).
- **Discord-уведомления**: автоматическая асинхронная отправка красивых Embed-сообщений через Discord Webhook при создании и завершении Королевской Дуэли.
- **Ограничения**: кулдаун 1 час на использование билета, максимум **1 активная** Королевская Дуэль одновременно на сервере.

### 4. 👁 Система зрителей и трибун
- Первые **15 мест** — бесплатные для всех игроков.
- Начиная с 16-го места — платная покупка билета с прогрессивной стоимостью.
- **Жёсткие границы трибун (SpectatorZoneGuard)**: зритель не может вылететь за пределы зоны наблюдения, провалиться под текстуры или вмешаться в поединок.
- Полёт разрешён только при наличии права `loveduels.spectator.fly` и только строго внутри зрительской зоны.
- Быстрый выход по предмету в хотбаре или команде `/duel leave`.

### 5. 🛡 Защита от абузов и дюпа
- **Полный Snapshot инвентаря**: сохранение всех слотов, брони, второй руки, эффектов зелий, уровня, опыта, здоровья и сытости с гарантией анти-дюпа.
- **Анти-релог**: мгновенное поражение при дисконнекте, конфискация ставки, штраф Чести и позорное глобальное объявление: *«Игрок X сбежал с дуэли против Y!»*.
- **Интеграция с LoveBehavior**: беглецы получают существенный штраф к рейтингу вежливости/кармы.
- **Кулдаун вызова**: нельзя вызывать одного и того же игрока чаще, чем раз в 10 минут.
- **Whitelist команд**: во время боя разрешены только доверенные команды коммуникации.

## 🎨 Стандарт интерфейсов (GUI)

Все меню разработаны в соответствии с единым дизайн-стандартом **gui-gen-5**:
- Размеры: **27, 36, 45, 54** слота.
- **Стекло только в Header и Footer**. В рабочей зоне стекла нет никогда.
- Голова игрока на слоте 0.
- Кнопки управления и навигации в Header/Footer.
- Полноценная поддержка Adventure API и MiniMessage градиентов.

## 📜 Команды и права

### Игроческие команды (`/duel`, `/дуэль`)
| Команда | Описание |
|---|---|
| `/duel` | Открыть главное меню дуэлей |
| `/duel <игрок>` | Быстрый вызов игрока с настройкой ставок |
| `/duel accept` | Принять входящий вызов |
| `/duel deny` | Отклонить входящий вызов |
| `/duel leave` | Покинуть наблюдение за дуэлью |
| `/duel spectate [игрок]` | Меню наблюдения или подключение к игроку |
| `/duel top` | Открыть Зал Славы (топ по Чести) |
| `/duel stats [игрок]` | Просмотр боевой статистики |
| `/duel rematch` | Предложить мгновенный реванш |

### Административные команды (`/lda`, `/loveduelsadmin`)
| Команда | Описание |
|---|---|
| `/lda arena create <id> [название]` | Создать новую арену |
| `/lda arena setpos1 <id>` | Установить спавн 1-го игрока |
| `/lda arena setpos2 <id>` | Установить спавн 2-го игрока |
| `/lda arena setspectator <id>` | Установить точку зрителей |
| `/lda arena setbound1` / `setbound2 <id>` | Установить боевые границы арены |
| `/lda arena setspecbound1` / `setspecbound2 <id>` | Установить границы трибун зрителей |
| `/lda arena delete <id>` / `list` | Удалить арену или вывести список |
| `/lda kit create <id> [название]` | Создать кит из текущего инвентаря |
| `/lda kit delete <id>` / `list` | Удалить кит или вывести список |
| `/lda give ticket <игрок> [кол-во]` | Выдать Билет Королевской Дуэли |
| `/lda forceend <игрок>` | Принудительно завершить дуэль |
| `/lda sethonor <игрок> <число>` | Изменить Честь игрока |
| `/lda reload` | Перезагрузить конфиг, арены и киты |

### Права (Permissions)
- `loveduels.use` — доступ к игроческим командам и меню (по умолчанию: `true`)
- `loveduels.spectator.fly` — полёт внутри зоны наблюдения (по умолчанию: `op`)
- `loveduels.admin` — полный административный доступ (по умолчанию: `op`)

## ⏱ Лимиты времени и механика ничьей (Time Limits & Draw)

- **Лимит времени:**
  - Матч без раундов: **12 минут** (настраивается в `config.yml` через `match_time_limit_seconds`).
  - Раундовый бой: **10 минут** на раунд (`round_time_limit_seconds`).
- **Индикация в BossBar:**
  - Динамический полосный индикатор обратного отсчёта для бойцов и зрителей.
  - Плавная смена цветов: **Зелёный** (хватает времени) → **Жёлтый** (осталось ≤2 минут) → **Красный** (осталось ≤30 секунд).
  - В Королевской Дуэли: **Пурпурный** стиль с золотой короной.
  - Звуковые сигналы на 60 сек, 30 сек и секундный метроном на последних 10 секундах.
- **Исход при истечении времени (Ничья):**
  - **Обычные бои:** фиксируется ничья. Ставки деньгами **полностью возвращаются** обоим участникам, Честь и статистика побед/поражений остаются без изменений («просто ничего не происходит»).
  - **Королевская Дуэль:** фиксируется ничья. Все денежные ставки и королевский билет **сгорают в королевской казне** («ставки пропадают и больше ничего»), Честь и статистика не меняются, глашатай объявляет о ничьей на весь сервер.
